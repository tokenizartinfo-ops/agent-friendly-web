# Tokenizart agent-friendly installation package

Prepared on 2026-08-26 by Agent Friendly Web for Gabriel Mucchiut and Tokenizart.

## Folders

- `tokenizart.com/`: candidate public files and structured data for the WordPress website.
- `atelier.tokenizart.com/`: candidate public files and structured data for the Atelier application.

## Maturity labels

- Files named `llms.txt`, `llms-full.txt`, `robots.proposed.txt`, `sitemap.proposed.xml` and `structured-data.json` are implementation candidates. They still require review, backup, preview and controlled release.
- Files ending in `.preview.json` describe future discovery catalogs. Do not install them at canonical paths until every listed artifact is reachable and its status is still correct.
- This package does not contain credentials, owner data, private APIs, Owner Live access or mutating tools.

## Installation

Follow `docs/TOKENIZART-INSTALLATION-RUNBOOK.es.md` in the public repository. A file counts as available only after the canonical production URL returns it correctly.
