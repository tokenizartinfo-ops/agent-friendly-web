# AFW: consentimiento durable y revocable del copilot — release cerrado

**Proyecto:** Agent Friendly Web, repositorio `tokenizartinfo-ops/agent-friendly-web`. **Entorno/origen:** producción `https://agentfriendlyweb.dev`, Worker `agent-friendly-web-web-production` (`7d04bb3c776e4bbabe7747f0dc1e0621`), D1 `d26fc9d2-df5a-4957-8e58-cc4c945faad8`. **Acción:** migración aditiva y versión productiva con copilot cerrado. **Rollback:** volver al 100% a `a4107b0e-7c14-48da-bde5-db2bd63361d6`; conservar la tabla aditiva y sus posibles constancias, sin restaurar ni borrar D1.

La versión anterior exigía aceptación por cada consulta, pero no guardaba un permiso por expediente. Esta versión agrega `copilot_consent_events` con secuencia monotónica, expediente, usuario opaco, acción `grant`/`revoke`, versión del consentimiento, clave de idempotencia y fecha. No guarda el texto enviado al modelo. El dueño puede activar o revocar desde el panel. El POST del copilot exige el último `grant` vigente **y** la casilla de cada consulta antes de cuota e inferencia; con `revoke` devuelve `403 project_consent_required` para consultas posteriores. Una revocación no cancela necesariamente una inferencia ya iniciada. El panel sigue siendo opcional: la guía local del expediente funciona sin permiso de IA.
