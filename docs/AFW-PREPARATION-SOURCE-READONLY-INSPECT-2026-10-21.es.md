# AFW — consulta del alta original sin repetirla
21oct2026 · cambio acotado de fuente sobre PR541.

El botón futuro «Consultar estado» debe poder leer el recibo después de una respuesta incierta sin volver a crear el expediente. Agregar inspect(input) al mismo store; input es la solicitud ORIGINAL de creación, no una confirmación nueva ni una fuente de identidad. Compartir normalización, identidad servidor, perfil y lease originales, lectura primaria, hash y comparación del recibo. La inspección de original completo retorna source_already_recorded; ausencia de ambos IDs retorna source_not_recorded. Datos incompatibles/parciales siguen source_conflict; errores y vencimiento source_unavailable, sin datos ni retry.
inspect jamás accede a batch/run ni prepara SQL de escritura; funciona con un adaptador que solo tenga prepare+lecturas. Configuración inválida/cerrada no invoca dependencias. El modo lectura/escritura queda en wrappers internos fijos, no en el input. create conserva su contrato y comportamiento, incluida una nueva llamada explícita con el MISMO original si ambos IDs están ausentes. Una ausencia observada NO prueba que una operación previa en vuelo haya fallado y NO ordena reintentar. No se renuevan ventanas ni identidad.
Ambos resultados mantienen flags de autorización/publicación/operación false; sourceRecorded solo es evidencia de lectura coherente, no de dominio verificado ni consentimiento. No nuevo HTTP endpoint/importador, esquema, rows reales, permisos, cliente, DNS o runtime.
