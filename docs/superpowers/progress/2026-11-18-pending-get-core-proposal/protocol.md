# AFW private Pending GET observer, B1 MODEL proposal

This directory is a detached proposal for one finite isolated GitHub Actions MODEL. The real factory slice from S09 is an immutable preimage. The ordered insertions in `extension.json` generate the new slice and their exact removal recovers the preimage. The sealed vectors are mounted by Git blob identity. `M01` uses the native Request, exact lease and Error, and the local Response from the RED assertion. The isolated child observes the original 503 and g1 and asserts the exact private field. The published frame carries its SHA-256 and omits the raw epoch and UUID.

## Main observer

`createGetWinnerObserver()` retains the existing public observer methods and their behavior. The private adapter may pass `{enabled: true, epoch, directProof}` with a presealed 16-digit lowercase hex epoch and a private identity object. The nominated fixture may call `enter(originalRequest, directProof)` only after independent bodyless/direct/native eligibility. Binding, race, catch and finish retain their original exact identities. The private proof is supplied by the fixture adapter and has no wire representation.

Use `observer.pendingM.mark(lease, boundary, response?)` with named boundaries `requestBytesEnter`, `requestBytesReturn`, `stubEnter`, `stubReturn`, `responseBytesEnter`. Supply the exact stub response on its normal return and on response-byte entry. `captureUuid(lease, value)` captures the already-produced UUID once in cursor 2. `markRead(lease, originalResponse, edge)` takes `enter`, `return`, or `responseBytesReturn`. `invalidate(lease)` marks an exceptional source path before original check or cancellation. Existing `deadline(lease, originalError, origin, arity)` takes the private provenance label and original argument count, which B2 must qualify against the actual unchanged timer and listener callback found in the original fixture. The original g1 finish obtains and validates headers itself. The private write reuses those same validated headers and the original exact locally constructed Response. The construction proof must establish that this Response starts without the private header.

## QA observer

`createPendingQa({enabled: true, epoch, directProof})` provides `arrive(originalRequest, originalUuid, directProof)`, `phase(originalRequest, next)`, `enterPair(originalRequest, originalOptions, caller)`, `aggregate(originalRequest, originalOptions, name, edge)`, `reaction(originalRequest, edge)` and `sample(epoch, key, directProof)`. `caller` is `initial` or `nested`. `name` is one of `facts1`, `primary1`, `qualify1`, `primary2`, `facts2`, `qualify2`; `edge` is `enter` or a normal `return`. `reaction` uses `F` or `R` from the existing promise handlers. The synchronous fallback contributes no hook. Pair inputs are the exact original options objects. `sample` returns one private fixed wire string for the first positive exact read, with terminal error and absence codes bounded by the same grammar.

## Host admission

Construct with `{enabled: true, epoch, directProof, expectedLabel, testIdentity}`. `capture(handle)` retains the exact original response, main, label, test, token, actor, generation, direct proof, status and g1. `take(context, proof, readMain)` consumes the mailbox. Context supplies the corresponding independently observed identities and booleans `beforeCutoff` and `reserveAvailable`. Proof supplies four contiguous target marks, row and byte caps, typed journal custody, `recorderIntact`, `countQualified`, and the original opaque `countSnapshot`. Only an eligible take invokes `readMain(originalResponse)` once. After a keyed take, one `startRead(invoke)` invokes `invoke(epoch, key)` synchronously and returns the adapter's result. The trusted adapter reports `completeRead('reply', wire)`, `completeRead('timeout')` or a terminal failure outcome. `staged()` returns the candidate final row for one bounded private write. `admit(privateFile, proof)` consumes admission and preserves one parsed matching row only when the original public frame, recorder, close return and terminal child were verified. The core performs no journal read, clock, actor call or file write itself. The MODEL invokes local functions and explicitly supplies typed facts for those boundaries.

## Review gates

The B1 MODEL seeds one transition budget in M and QA through separately granted single-use private callbacks. The QA ordinal seed independently constructs C, ordinal 63, K=c, reaction 0 and accepted-write count 0 for Q32. B2 must exclude these registration paths from ordinary mounted code. Any approved native seed remains a separate explicit fixture-only capability.

B2 must separately qualify the unchanged source boundaries, same-file afterEach ordering, native Request and Response identity, original count and journal custody, one real bounded actor read, continuation and cleanup. All rows leave QA at the M cutoff, outward settlement/delivery, QA catch and business result unknown. No positive q0.A delivery inference follows.

The proposed runner reuses the prior RED PID/network namespace, empty credential environment, unprivileged identity, bounded process streams, named PID check and temporary copy/closure pattern. The child shares the runner's file identity. This is not filesystem isolation or proof that a process could not access credential files. The scope requires independently reviewed fixed code, sealed synthetic DATA and no credentials supplied to the child. The exact evidence carrier and confirmed upload describe different layers; raw artifact archive authentication requires independent archive bytes.
