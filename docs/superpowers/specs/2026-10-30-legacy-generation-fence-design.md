# Legacy canary host fence after QA generations
AFW source-only; same actor/storage and unchanged public routes. A common read-only fence wraps all three native transaction callback routes: central control tx, privateStorage.transaction and reduction/dispatch journal. Before work and after await work, in the same native transaction: any defined V2 HEAD blocks (including malformed/null/false); INFO/CONTROL prefixes limit1 must be Map and empty. Stable get/list methods, actor and original wall/monotonic clocks are checked after every await.
Only internal status is exempt, for sanitized historical V1 observation. Its cancellation state is local to the legacy host; the future generation host must use separate controllers. No new effects, migration, binding or API. No cancellation of already-emitted HTTP is claimed.
Native tests inject an orphan inside each formerly direct transaction and require rollback/history preservation. Existing V1 native positive remains; preexisting HEAD/orphan blocks legacy arm/withdraw/restore/reduce without changing V1 data. Missing/throwing list fails closed for writes. New V2 ARM still independently requires predecessor withdrawn+expired; this fence does not replace that condition.
