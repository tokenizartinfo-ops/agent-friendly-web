# Agent Friendly Web Gate 6D.4D1 Operating Position v0

**Fecha:** 2026-09-04

**Estado:** decision operativa aprobada; prueba de concepto sin validacion comercial

## Decision

Agent Friendly Web se tratara por ahora como:

- una prueba de concepto y subproducto experimental de Tokenizart;
- una iniciativa creada e impulsada por Gabriel Mucchiut;
- un producto todavia sin validacion comercial;
- una superficie tecnica propia bajo `agentfriendlyweb.dev`, con repositorio, datos y despliegues separados para evitar errores operativos;
- una eventual linea de servicios comercializada y facturada por Tokenizart Group LLC si aparece una primera venta.

No se creara ahora una sociedad, unidad de negocio formal, cesion de propiedad intelectual, licencia interna, registro de marca, estructura fiscal separada ni documentacion juridica extensa.

## Explicacion simple

La relacion se expresara asi cuando resulte necesario:

> Agent Friendly Web es una prueba de concepto de Tokenizart creada e impulsada por Gabriel Mucchiut.

Si existe una cotizacion o factura, el vendedor sera Tokenizart Group LLC y el concepto identificara el servicio de Agent Friendly Web. No se usara el shop de Tokenizart.

## Separacion tecnica

Que sea un subproducto de Tokenizart no autoriza a mezclar:

- bases de datos o contactos;
- repositorios y ramas;
- Cloudflare Workers, D1, R2 o Access;
- secretos y permisos;
- datos de usuarios de Atelier;
- despliegues de Companion, Copilot u Owner Live.

Esta separacion es una medida tecnica y de seguridad. No pretende definir hoy una estructura societaria independiente.

## Operacion durante la prueba de concepto

- Se continua desarrollando y probando el producto con costos minimos.
- No hay checkout publico, suscripcion automatica ni pagos por agentes.
- Las auditorias publicas siguen siendo read-only y no requieren email.
- Los pilotos con datos reales de terceros permanecen deshabilitados.
- La primera prueba humana privada puede usar unicamente datos propios de Gabriel y Cloudflare Access.
- Si aparece una venta, se prepara una cotizacion simple y una factura de Tokenizart Group LLC con el servicio claramente identificado.
- Los ingresos y costos se etiquetan con una referencia `AFW` para poder medirlos sin crear otra contabilidad o infraestructura.

## Identidad editorial inicial

Las comunicaciones editoriales podran presentarse con estas capas claramente diferenciadas:

- **marca y remitente visible:** Agent Friendly Web;
- **autor personal cuando corresponda:** Gabriel Mucchiut;
- **pie institucional breve:** `Agent Friendly Web by Tokenizart Group LLC`;
- **direccion de respuesta:** una cuenta verificada del dominio de Agent Friendly Web cuando este operativa.

Esta formula permite que Gabriel publique analisis, novedades o aprendizajes con voz propia sin crear ahora otra entidad. El pie identifica el marco comercial inicial y no debe interpretarse como una cesion definitiva, una sociedad separada ni una declaracion sobre titularidad futura.

La identidad editorial no habilita envios. Toda newsletter futura requerira consentimiento `product_updates` separado, prueba del texto aceptado, baja simple y verificable, lista de supresion y trazabilidad del remitente. Hasta completar ese gate, `AFW_PRODUCT_UPDATES_ENABLED=false` y no se importa, infiere ni reutiliza una lista de destinatarios.

## Unica constancia interna

Una nota privada registrara solamente:

- que Agent Friendly Web nacio como prueba de concepto de Tokenizart;
- que fue creado e impulsado por Gabriel Mucchiut;
- que una venta inicial se canalizara por Tokenizart Group LLC;
- que no existe una cesion ni una separacion societaria formal;
- que el tema se revisara cuando exista monetizacion frecuente.

No se necesitan mas documentos internos en esta etapa.

## Cuando reabrir la definicion

La estructura comercial, societaria, fiscal y de autoria se revisara solo cuando ocurra alguno de estos hechos:

- facturacion frecuente durante varios meses;
- volumen o responsabilidad economica material;
- incorporacion de socios, empleados o proveedores que creen propiedad intelectual;
- ingreso de inversores o due diligence;
- integracion comercial real con Atelier o el shop de Tokenizart;
- operaciones recurrentes, cripto o x402;
- expansion que exija una definicion juridica o fiscal concreta.

Hasta entonces no se incurre en gastos profesionales o registrales anticipados, salvo una obligacion concreta derivada de una venta o tratamiento de datos real.

## Gate siguiente

Esta decision permite continuar con el desarrollo tecnico. No habilita por si sola:

- captacion publica de contactos;
- newsletter;
- datos reales de clientes;
- cobros automaticos;
- x402;
- herramientas mutantes;
- mezcla de recursos con Tokenizart.

El siguiente paso es el piloto humano privado del ciclo de privacidad con datos propios de Gabriel, detras de Access y con todos los flags publicos en `false`.
