## Block5: observation/cost ledger
Create examples/agent-consumer/trial-ledger.mjs: summarizeEfficiencyTrial(input) pure and bounded. Contract afw.efficiency-observations.v1; trialRef, currency uppercase3 syntax only, cases<=200, observations<=1000, mode synthetic/declared_observation. No tariff, payment, provider calls, token estimation or evidence attestation.
Cases: strict caseRef,variant direct/afw,conditionsRef,outcome accepted/failed/pending,acceptanceRef; accepted requires opaque ref, others null. List only actually started occurrences, not planned leads; failed/pending remain in denominator. Duplicate case/variant rejected. Same case across variants requires same conditionsRef; reference consistency does not prove equal real-world conditions.
Observations: observationRef,caseRef,variant,category,attemptRef|null,observedAt canonical nonnegative ISO, costMicros|null, costBasis, costRef|null,usage|null,usageRef|null. Six required categories per case: consumer,afw,persistence,verification,human,recipe. costBasis observed_variable/approved_allocation requires safe nonnegative integer micros+opaque receipt; not_applicable requires exact0/null receipt and cannot coexist with other rows in that case/category; unknown requires null/null. Missing category or unknown cost -> totalCostMicrosnull, retain knownCostMicros and unknown coverage counts. Do not impute entire shared account/subscription; each attribution needs its own method/receipt. Integers and sums <=safe representable; reject fractions/negatives/overflow.
Observation ID duplicate exact projection deduplicates a delivered measurement; same ID with changed content blocks. A new attempt/ref remains in spend even if an idempotent operation replay returns same capsule; request identities count only as recordedAttempts, not claimed full API telemetry. Unknown observed attempt may have consumed resources. Include spend for failed occurrences and retries.
Usage record exact inputTokens/outputTokens/cachedInputTokens/requestBytes/responseBytes, each safe integer ornull; needs attemptRef/usageRef, cachedInput<=input when both known. At most one usage record per variant/attemptRef; multiple cost components must not double count same usage. Unreported usage for a recorded attempt staysnull; bytes never convert to tokens, cachedInput is a subset, never added to inputTokens. Retain known usage subtotal separately if partial.
Per-variant attempted/accepted counts, acceptance rate as exact numerator/denominator, total/known cost and missing coverage, recordedAttempts/observations, usage and knownUsage. Cost per accepted = exact rational totalMicros/uniqueAccepted only if total complete and accepted>0; otherwise null. Never divide only successful spend or count retries as new cases. No savings/recommendation/price output; isEfficiencyEvidencefalse and source observation mode remain explicit. Opaque references and numeric summaries only, no raw private text/headers/keys/URLs.
Synthetic demo uses TST syntax/cost labels explicitly fictional, not an approved currency/tariff or real measurement. Manual collection/integration required before useful real observations; this is ledger validation/aggregation, not automatic metering.
