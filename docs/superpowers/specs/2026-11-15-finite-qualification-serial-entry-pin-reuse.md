Use exactly three process-local lazy pristine slots keyed by the fixed names lifetime.py, delivery-outer.mjs and controls-outer.mjs. Accept a hit only when the freshly read bytes are fully equal to the corresponding startup `pristine[name]` buffer. That map already exists. Its Buffers must remain private and unmodified; freezing the map alone does not freeze Buffer contents. Store the computed canonical pin string, which is immutable. No persisted cache, mutable-object identity key, path/mtime/length-only hit, or unbounded map of mutated input. Compute a first pristine pin with the normal Node algorithm from actual equal bytes. Historical embedded Python-generated gzip/base64 literals are not substitute cache values.
2. Preserve the original read/validate/write order: one kernel read at call start, the module read for each of the three entries, the unique `_r3_kernel=` and `_r3_module=` needle checks, then each original write from `pristine[entry]`. Reuse the pin for the same captured kernel. For the two delivery-module reads within one call, retain a private first-read buffer and serialized pin and compare the fresh second read in full.
