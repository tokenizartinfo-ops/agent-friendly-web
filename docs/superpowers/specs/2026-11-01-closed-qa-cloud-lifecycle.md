## Original finite clock
Native context startAt = comment.created_at; expiresAt=startAt+300000; cleanupExpiresAt=expiresAt+180000. Queue/build/preflight consume that same window; do not move its origin. Begin the write sequence only with >=180000ms remaining. Native v2 remains a metadata diagnostic: queue<5000ms, active execution<5000ms, captured total<10000ms, bounded by original context. Actual ARM/v1 budgets unchanged. A dedicated job has12min upper bound; transport uses original wall AND monotonic deadlines, per-request caps and no retries. N1=createdAt+300000 and R1=N1+180000. Cleanup uses independent abort/transport state but the SAME original wall and monotonic origin ending at R1; no refreshed lease. Nominal abort/failure cannot poison cleanup, and the180s nominal margin is not required for restoration. Every final GET is also bounded by R1; an expired trial cannot authorize another trial.

## Failures and evidence
401/403 means stop; never widen the token or borrow another credential. Network errors and unknown ACKs preserve uncertainty. One Node try/finally gives normal cleanup, not a guaranteed guard against runner loss. A killed runner may leave the ALL-FALSE candidate active; the compiled context still expires, but restoration remains UNPROVEN. Do not claim native withdrawal, guard liveness, PC-off or a permanent scheduler. No second blind cleanup writer, claim refund or automatic retry.

Record only source/comment/run/attempt/intent IDs, hashes/counts, stages, timestamps, finite counters, restoration identity and sanitized proofs. Raw modules, provider bodies and credentials never appear in logs/artifacts. Existing readback remains immutable in purpose. Posting a new live command needs its own concrete intent receipt, source/review/CI acceptance and fresh preflight; this source plan alone posts no command.

## Closure criteria
Cloud tests exercise denied admission, stable claim/dedup, lost ACK, expired/rollback clock, mutation budgets, exact candidate bytes/config, foreign deployment, failed native result, cleanup after errors, final readback and sanitized outputs. Exact-head independent review and CI pass before merge. One separately recorded live CLOSED QA intent may then demonstrate the finite cloud lifecycle; it still does not close generation ARM, useful event delivery, native unsubscribe or integrated PC-off.
