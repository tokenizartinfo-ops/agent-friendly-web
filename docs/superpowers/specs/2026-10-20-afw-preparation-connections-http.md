## Intent and selected approach
A person must see the actual saved scope/expiry/state of their preparation permission and withdraw it, including AFTER the original agent profile has expired or issuance is disabled. Preserve proposed files/history; never reconnect, renew consent, approve installation or charge. Human-readable comic typography/palette and calm guidance reuse the established view. The owner explicitly requests autonomous design/implementation/merge of consecutive source blocks and delegates routine decisions; this standing instruction overrides skill sign-off menus, NOT live access/consent/customer gates.
This is architectural composition of existing identity, D1 grant/nonce store and presentation, with a detached new host. Alternatives: reusing the old read Worker wholesale would inherit a window gate/read-only scope and hide withdrawal after expiry; a generic admin proxy/new signing secret would enlarge authority and custody. Choose a narrow source-owned default-closed connections handler, no new secret or remote resource.

## Routes, identity and primary isolation
Only fixed same-issuer GET /connections and POST /connections/revoke; no selector/query/hash/external redirect; URL<=8192bytes. Fresh actual Access verifier resolves subject, never browser fields. Native CI uses signed ephemeral RS256 and existing verifier; not real Cloudflare issuance/JWKS/human-session proof.
Rate key hashes verified subject + original profile; requests failing validation/identity never read or write permission data. Body POST exact handle/grant, form-urlencoded UTF8 actual<=4096bytes, no duplicates/unknown fields/encoding; Origin must equal canonical issuer. Cookie must contain exactly one matching __Host-afw-preparation-revoke value; Secure/HttpOnly/SameSite=Strict/Path=/.
Primary saved grants JOIN admitted delegated_preparation_consents on actual grant/user/client/project/resource/creation/expiry/scope and exact original profile/dates. Bounded21 rows: >20 is unavailable, never a falsely complete list. No project answers or current new-owner organization is read; generic dossier label plus configured trusted clientName. The original grantee can withdraw their OWN historical permission after project transfer, without seeing the new owner's data.
State revoked takes precedence, otherwise expired if original grant end<=now, otherwise active SAVED permission. Text explicitly distinguishes saved state from current successful authorization/connection/work. No scope inferred from a generic client or request.

## CSRF and withdrawal
Reuse existing delegated_consent_sessions ONLY for hashed one-use operational anti-CSRF receipts, kind='preparation-revoke:'+SHA256(original profile tuple). Not an OAuth consent or agent grant. GET writes at most one random nonce receipt after list validation, scoped to subject/project/client/resource/original profile, expiry clamped to original management end (not agent end). No new DDL or raw handle in storage/logs. No form on an unavailable response.
POST validates current identity/config/deadline, matching cookie/handle and exact stored nonce context. One existing consumeConsent conditional UPDATE; unknown ACK stops without retry or permission mutation. After acknowledged consumption, reverify identity and primary target.
One target-only conditional UPDATE sets revoked_at if still empty, fences subject/client/project/resource/admitted original consent and SQL real clock<original request+management deadline, RETURNING receipt. No broad revocation, reset, delete, SDK KV mutation or historical capsule/event mutation. Already withdrawn target is idempotently read, not written again. Unknown ACK returns unavailable; subsequent explicit GET can truthfully recover observed state, no automatic mutation retry. Final primary read and identity/config/deadline recheck precede success303 to same /connections. Receipt/read must show current revoked state; no physical provider-token deletion/cancellation claim.
Late queued SQL must enforce its original absolute deadline in SQL; an aborted/timed-out response is not a cancellation guarantee. No late token/identity data or success claim. Native connected MCP checks actual D1 denial after withdrawal.
