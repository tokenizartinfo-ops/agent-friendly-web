# Host primario del instalador y cierre

Diseño dentro de la ruta autorizada: conservar SAME preregistry SQLite, crear el productor por invocación y reutilizar su scope para el instalador existente. installOwn sin payload; D1 ligado a AFW_QA_DB, flag explícito defaultfalse y dependencia privada AFW_QA_OCCURRENCE_DISPATCH.dispatch obligatoria ANTES de cualquier escritura. Esa dependencia no existe en el runtime actual: fuente cerrada hasta conexión real; ninguna fixture/callback constante en producción. dispatch_attempted significa llamada, no ejecución cloud exitosa.

No exponer permisos de inicio o consumo por RPC. Usarlos solo dentro del instalador; envolver sus operaciones vivas con el checkpoint conjunto existente y añadir intent/finalización/consumo a las capturas. Custodia/admin write y preflight/admission permanecen gates reales del despacho futuro; binding D1 propio no acredita permiso externo.

readOwnInstallationHistory es documental. readOwnClosureScope defaultfalse: registro configurado debe coincidir con preregistro original, reserva/historia propia completa, intent válido write_started, finalización validada contra D1 propia independiente, consumo si existe validado. Solo reserved, no retirada primaria/preregistral; expiración permite exclusivamente cierre, D1 revoked puede ser resultado esperado del cierre. Capturas primarias antes y después de las esperas externas iguales; comparar procedencia D1 y aprobación completas. No reconstituir dispatch, renovar fechas ni usar un pointer legacy.

IndependentClosure opta explícitamente por lector de SAME preregistry; sin flag conserva la composición legacy cerrada. Nuevos métodos internos sin HTTP/rutas/namespace/migración o despliegue remoto. Fixture nativa de HTTP, identidad y dispatcher declarada sintética: escritura D1 real local y presupuestos primarios. Casos: falta dispatcher cero escritura; dos instalaciones un write/consumo/dispatch; historia no replay; cierre antes/después D1 revoked; retirada niega catálogo. Revisión única final/fixpass, checks proporcionales y CI exacthead.
