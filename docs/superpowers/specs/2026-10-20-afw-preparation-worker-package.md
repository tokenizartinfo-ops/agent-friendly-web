## Runtime source interface
Create worker/mcp-preparation/index.mjs. Export createDelegatedPreparationWorker(options={}) -> frozen {fetch(request,env,ctx)}; default export is the no-options production Worker. Exact trusted options only accessVerifier?, now?, monotonic?; the production default supplies no synthetic verifier. These are source integration options, never request/JSON/header fields. Reuse createDelegatedPreparationRouter; no custom SDK, registration API or legacy fallback.
Closed-by-default fetch: env.AFW_DELEGATED_PREPARATION_ROUTER_ENABLED !== 'true' returns fixed no-store404 without looking at DB/KV, other config, body or identity. Missing/invalid enabled server config returns opaque no-store503/authorityflagsfalse, not a reflected error. Five routes remain only /authorize,/oauth/token,/mcp,/connections,/connections/revoke through the existing router. No discovery/register/refresh/admin/health API is added.
Request-local composition intentionally creates a fresh private router/AS per request while sharing actual KV/D1. It does not renew grants or dates; all original dates are explicit server config and D1 is rechecked per operation. Same-factory observed drift fencing from PR522 remains a request/factory guarantee, NOT persistent/cross-isolate revocation. Configuration restoration in another request is not claimed as a durable tombstone; actual withdrawal is durable D1. This avoids assuming Workers preserve env object identity between fetch calls or caching authority across requests.

## Trusted server configuration
Issuer from AFW_OAUTH_ISSUER must be a canonical HTTPS origin; AFW_OAUTH_RESOURCE must equal issuer+'/mcp'. Project/client from existing AFW_OAUTH_PILOT_PROJECT_ID/CLIENT_ID, checked by existing ref/oauthClientRef validators. ProfileId fixed afw.preparation-consent.v1.
Original dates: AFW_PREPARATION_TRIAL_STARTED_AT and existing AFW_OAUTH_PILOT_EXPIRES_AT; independent human AFW_PREPARATION_MANAGEMENT_STARTED_AT/EXPIRES_AT. Each is canonical UTC ISO with milliseconds and safe representable nonnegative timestamp. Each positive window<=600000ms. NO Date.now()+duration default or renewal on construction/render/retry. Expired agent profile is allowed for independently valid management; too-short management leaves agent ports absent per PR522, not extended or rejected in a way that hides withdrawal.
AFW_PREPARATION_CLIENT_NAME is required bounded nonempty text<=200; AFW_PREPARATION_LOCALE is es/en/pt, absent defaults es. Existing dependency/flag validation stays in accepted hosts. Config vars are trusted server values, not a sandbox of hostile proxies; enabled request reads only a fixed bounded list. No env JSON configuration, URLs, callbacks or client fields come from the request.

## Original ingress lifetime and drift

Capture raw scalar server fields once, then check their exact values through source clock wrappers during all existing child waits; observed drift is terminal for that request. Trusted options references, wall/monotonic and original signal are also retained; no new async response proxy or post-child handoff authority decision. Existing MCP boundary checkCurrent handles final output. Original 4096/32768/8192 caps, identity/origin/rate/primary SQL checks and finite cleanup remain authoritative. Source-entry initialization is synchronous/bounded; no IO before original lease.
Module/factory creation must not issue a token, access remote services or touch user data. The entry does not export SDK internals or expose a bootstrap route. Native fixture bootstrap belongs only in test/fixtures.
