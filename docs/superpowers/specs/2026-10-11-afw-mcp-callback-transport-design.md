# Private Node callback transport

Purpose: send the accepted signed envelope byte-for-byte after separate live host authorization. No endpoints, subscriptions, custody, scheduling or customer operations in this block. Owner authorizes autonomous design/execution; reuse existing isolated AFW worktree and execute inline.

`sendSignedMcpCallback(url, envelope, signal?)` returns frozen `{status,body}` only after complete bounded UTF-8 response. Generic static error on every rejection; no URL/body/key/cause logging. Snapshot exact own data descriptors for frozen envelope and its five fixed signed headers before any await. POST only; request body max262144bytes plus max8192bytes headers. No caller TLS/proxy/DNS/method/header options. No retry/fallback/redirect, agent:false, automatic family selection disabled. Hostname remains original for Host/SNI/native certificate validation.

URL HTTPS/443, FQDN, no credentials/fragment/IP literal/control whitespace, length<=2048. Resolve A and AAAA with a new native Resolver each request. Only ENODATA/ENOTFOUND mean an absent family; other resolver errors deny. At most64 total records, all valid and permitted; choose one fixed address and return only that in HTTPS lookup. Independent network policy rejects all IANA special IPv4 prefixes, multicast/reserved; IPv6 only2000::/3 excluding all special subsets, IPv4 embedding and zone IDs. This deliberately rejects service-anycast special exceptions and does not promise routability. Tables reviewed against IANA registries dated2025-10-09.

One5000ms hard deadline from invocation includes DNS, TLS, headers and complete body; abort destroys request/response and cancels this resolver. Response limit1024bytes, maxHeaderSize8192, no encoded/compressed body, fatal UTF-8 decoding, incomplete/aborted response denied. Any non2xx (including redirects) rejects without following Location. Receipt means callback HTTP reception only, never cloud task completion.

Tests: pure URL/IP boundaries and malformed inputs; test-only esbuild overlays of native imports for controlled DNS and a local HTTPS connector with ephemeral OpenSSL certificate. Connector checks the production-pinned lookup/options before dialing loopback with test CA. Real native TLS chain/hostname and POST bytes are exercised; synthetic DNS/loopback connector does NOT prove hosted public egress, already separately proven by the retired Container spike. No bypass flag or injected connector in product API. DNS mixed/private/error/empty, new DNS per request, frozen snapshot/accessor rejection, wrong hostname/chain, redirects, sizes/encoding/UTF-8, abort, stalled DNS/headers/dripping body deadline. Real subscription/host authority and a future bounded hosted mount remain gates.

References: [IANA IPv4](https://www.iana.org/assignments/iana-ipv4-special-registry), [IANA IPv6](https://www.iana.org/assignments/iana-ipv6-special-registry), [Node HTTPS](https://nodejs.org/docs/latest-v22.x/api/https.html), [Node DNS](https://nodejs.org/docs/latest-v22.x/api/dns.html).
