# Read-only QA generation observer
Date2026-10-30. Source-only integration prerequisite; no runtime or new binding.
createPrivateQaGenerationObserver({storage,capsule,now,timeoutMs}).read() has no parameters, pin, eligibility or mutator. It shares exactly the ledger's canonical parsers, bounded lineage/scan checks and original read lease. It uses only get/list in one native transaction and must never access put.
Return purpose afw.qa-generation-resolution.v2 with status, isHead, withinWindow, hashes/sequence/times and STORED runtimeVersionId/sourceRevision/storedContext. No capsule, grant or chain is returned. Every authorizesEffects, guardLivenessVerified, operationalReadiness, mayRetry flag is false. Unknown/timeout returns blocked; no late acceptance. Historical rows remain readable and expose their old identity explicitly.
The ledger keeps its mandatory executionPin and mutation API unchanged. No public skipPin mode is introduced.
Future fixed DO resolver may read this metadata and then construct a pin against the stored expected UUID, using the COMPILED QA source revision. It must explicitly compare that compiled revision with stored sourceRevision, require storedContext durable_object, current HEAD armed/vigency and all independent authorization/primary fences. The Workflow creates its own pin with context workflow; it compares UUID/revision rather than equating a DO snapshot with a Workflow snapshot.
Observer is never an ARM bootstrap: root still provides an expected UUID after correlating module/config/bindings. An observed stored UUID is not proof of native origin or live guard. Cleanup/historical observation must not become nominal execution.
Tests: reader with put getter that throws; immutable snapshots; absent/pending/withdrawn/non-HEAD/expired statuses; old stored identity under newer code; complete corruption/orphan/rolled-back HEAD matrix; hung get/list deadline and late completion; native DO persistence. Full ledger/native regressions must stay green.
