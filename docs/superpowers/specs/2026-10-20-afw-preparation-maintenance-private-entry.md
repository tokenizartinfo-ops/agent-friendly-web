## Outcome and selected boundary
Make accepted PB6 callable through a separate private Workers RPC entry, not through the preparation OAuth/human/MCP router. No deploy, target name, service binding, schema/client/app/permission/credential or management window is installed. PB5 stays closed. Old release operator is hardwired to other resources; do not repurpose it.
Official sources consulted21octUTC: https://developers.cloudflare.com/workers/runtime-apis/bindings/service-bindings/rpc/ ; https://developers.cloudflare.com/workers/runtime-apis/rpc/visibility/ ; https://developers.cloudflare.com/workers/testing/miniflare/core/multiple-workers/ .
Selected private service-binding capability: explicit caller deployment must receive a binding before it can invoke RPC. Shared account alone is not an approved caller. HTTP always closed; no bearer token or caller-supplied credential invention. Rejected public DCR/admin endpoint, CI bootstrap route in production, broadening existing G2 operator, or raw SDK KV fabrication.
This source is NOT an authorization service. The future deployment must separately prove caller identity/authorization, sole approved binding consumers, resource ownership, policy provenance and rollback. Cloudflare administrators able to change bindings remain trusted infrastructure actors.

## Interface
worker/preparation-maintenance/index.mjs default named class extends WorkerEntrypoint. Only custom public methods register(...args) and reconcile(...args); zero arguments, no target/client/redirect/dates or options accepted from RPC. Private implementation stays #private or module-local, no public getters for env/config/helper/API. Return only PB6 sanitized result; own failures are opaque with five authority/readiness flagsfalse and automaticRetryfalse.
fetch always fixed no-store404 with no body/config/dependency reads, regardless of path/method/flag. No scheduled/queue/event, OAuth, discovery, grant/project/fact/bootstrap, update/delete/reset/refresh or generic fetch method is exposed.
Disabled AFW_PREPARATION_CLIENT_MAINTENANCE_ENABLED !== stringtrue returns unavailable without reading other config or bindings. Enabled accepts only fixed trusted server fields: existing AFW_OAUTH_ISSUER/RESOURCE and AFW_PREPARATION_CLIENT_MAINTENANCE_POLICY JSON string<=2048bytes. Exact policy keys: redirectUri,operationId,startedAt,expiresAt. PB6 validates exact callback/issuer/resource/operation/window and four literalfalse preparation flags.
Snapshot those raw scalar fields per invocation and invalidate irreversibly on detectable drift via PB6 wall/monotonic wrappers. Default native Date.now/performance.now only; no exported clock/verifier/SDK injection. Fresh RPC instances share real DB/KV and original dates, never reset a slot or infer a retry. PB6's original5s lease, D1 primary clock, SDK ACK binding, original<=10min window and uncertainty semantics remain unchanged. No cancellation/global KV freshness guarantee.
