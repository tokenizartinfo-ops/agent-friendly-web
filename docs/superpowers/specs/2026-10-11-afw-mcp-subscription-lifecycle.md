# Private finite subscription lifecycle

Owner requests autonomous completion toward cloud supervision, not another unbounded guard or customer invitation. Implement inline in existing isolated AFW checkout; no deployment or secret copying in this source block.

Factory createMcpSubscriptionController uses ONE trusted transactional storage namespace, a server authorization resolver and a private32-byte custody key. Default callback sender is accepted pinned Node HTTPS transport; internal host injection is for composition/tests, never request input. Resolver must return exact principalRef/resourceRef/projectRef/permissionRef SHA256 identifiers, enabled boolean and absolute consent expiresAt. These are host-resolved monitoring consent, not inferred read-token rights. Private helpers do not authenticate originals themselves.

Canonical subscription identity includes principal/resource/project, event and canonical callback; secret and callback stored together under AES256GCM with fresh IV and AAD bound to ID/generation/purpose. No plaintext URL/key/secret in persistence or public receipts. Frozen descriptor-safe request snapshots precede awaits. QA lifetime <=10min from initial creation and current consent, shorter requested TTL honored, null never infinite. Same-secret refresh may reuse verification within that window; replacement secret rejected until dual-signature rotation exists. No replay cursor. Terminal withdrawal cannot be revived automatically.

Prepare one pending generation and spend its verification attempt in ONE transaction before network. Only the first acknowledged creation may send a CSPRNG single-use challenge; failed/lost ACK/restart cannot recreate a send permit. Existing pending request denies; active duplicate can return same ID after live authorization without a new challenge. Late challenge response activates only same pending generation/current consent/window; withdrawal wins. Unsubscribe is idempotent for authenticated matching principal/resource/project even when monitoring consent disabled/expired; it cannot modify another owner.

Deliver one exact matching metadata event with durable one-occurrence budget spent before callback. Failed/unknown ACK/restart cannot resend. HTTP receipt is separate from completed cloud review. Every live action rechecks permission and stored generation/window after waits; no request payload chooses owner or storage. Local cancellation helps same-process withdrawal; other-process withdrawal blocks final activation/next delivery and cannot undo a request already in flight.

Tests use native node:sqlite with serialized transactions, two controller instances, real encryption/decryption and deterministic authorization/clock/network fixtures. Tests do not prove actual host authorization, public callback or cloud execution. Cover duplicate/concurrent/restart, lost transaction ACK, wrong principal/filter, finite expiry/refresh, changed secret, revoked permission during verification, concurrent unsubscribe, encrypted persistence/tamper/wrong key, one delivery and unknown response, static sanitized errors. Fresh whole-branch reviewer once; proportionate focused/full/lint/build/exact-head CI before merge. Native worker mount and live account/plugin acceptance remain separate gates.
