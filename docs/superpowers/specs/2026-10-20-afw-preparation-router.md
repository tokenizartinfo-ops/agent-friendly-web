## Goal and approach
Compose accepted consent HTTP, authorization/token host, MCP mount and human connections into one detached default-closed request handler using the SAME actual SDK authorization server/KV and D1 context. No production entrypoint imports it, no runtime or DDL/config/client/permission changes. G2 is CLOSED; no OTP or repeated trial.
Selected: direct route delegation with one original ingress lease; no second async proxy or response-read phase that could label an inner handoff failed after the child already committed authority. Alternatives rejected: copying old read-only Worker would widen scope policy and duplicate authority; generic callback/fetch factory would accept arbitrary server behavior; outer async response proxy risks resetting budgets or an unowned post-handoff rejection. Five fixed paths ONLY: /authorize, /oauth/token, /mcp, /connections, /connections/revoke. Metadata/discovery, dynamic registration, refresh, arbitrary callback/old-Worker fallback are NOT part of this router and return404. It is NOT yet a complete externally discoverable service.

## Interfaces
New lib/delegated-preparation-router.mjs: createDelegatedPreparationRouter(options)->null by default or handler(request,ctx,originalLease?)->Promise<Response>. Trusted exact options: enabled,issuer,env,profile,management,clientName,locale?,accessVerifier?,now?,monotonic?. Require explicit env.AFW_DELEGATED_PREPARATION_ROUTER_ENABLED='true'; strict source options/profile/management/clock/root flag drift terminal. Original profile is afw.preparation-consent.v1 with server-fixed project/client/resource/start/end<=600000ms; management is independent original human window<=600000ms. Root global guard never turns agent expiry or issuer-flag closure into renewed authority or a reason to hide withdrawal.
Human connections created independently. Agent ports are created only at construction under active original profile and both existing issuance flags. Failed agent construction closes agent routes only; it does not grant fallback or silently reopen later. Agent flag closure after construction fences those handlers; own withdrawal remains independent. Root clock wrappers are supplied to every child so root configuration drift is checked during child awaits, not in an added post-handoff phase. Source module graph owns the actual AS privately; token validation uses AS.validateToken(audience,token,SAMEenv), not token decoding or a synthetic validator. No public SDK/registration API is returned.

Every selected request creates its original opaque <=5000ms lease BEFORE route parsing. Optional originalLease is trusted server-only, WeakMap recognized, never serialized/header/JSON authority. Borrowed lease must be current; no silent fallback to a new lease. Parent owner closes it; borrowers never close a parent's lease. Standalone behavior remains: children create/close their own lease when no lease supplied. Root delegates the SAME opaque lease to children; no extra await, parsing, body/output read, retries or success remapping after their own final handoff. Root's finally closes only its OWN lease; original route responses and existing finite2s privilege-reducing cleanup retain their meaning. Cleanup isn't cancellation or permission renewal.
Existing handler signatures gain optional trailing originalLease: consent(request,ctx,lease?), token.fetchToken(request,ctx,lease?), connections(request,ctx,lease?), mcp(request,ctx,lease?), and HTTPboundary(request,env,ctx,lease?). Same lease propagates boundary→OAuth/preparation SQL cutoff. Missing/invalid/closed/aborted supplied lease fails closed before body/auth/D1, without reset. Existing direct callers unchanged.
