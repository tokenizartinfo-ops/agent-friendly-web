## Primary private control
Private SQLite DO key afw.canary-restoration-control.v1 stores exactly purpose,planHash,policy,armedAt,withdrawnAt. armedAt may be null only for a terminal pre-arm withdrawal tombstone; at least one date is present. The raw policy contains only reviewed resource pins, no credentials. arm requires enabled true, matching original canonical policy/hash/namespace and bounded original dates; at most10minutes until start and original policy<=10minutes. Record once; same existing row returns original armedAt without renewing. A withdrawn row never rearms and no reset/delete/move API exists. Unknown native storage ACK is uncertain, never a positive arm receipt.

withdraw is a private reduction and remains possible after expiry or the env flag becomes false, but only for the matching stored hash in the fixed private actor. If no row exists but the hash matches a valid current server policy, record a terminal pre-arm tombstone so a queued arm cannot override a confirmed withdrawal. Latch withdrawn before awaiting its terminal transaction, abort all in-flight host signals, preserve original row/time and never re-enable. A lost ACK cannot be described as confirmed. status reads only that control and dates, no provider or original RPC; not readiness.

Do not equate an env edit in an archived Workflow with current authority. arm/restore read the private primary record; storage/dependency boundaries refresh it. A host object is retained within the DO so an interleaved withdraw invalidates its synchronous control callback. Instance recreation reconstructs from primary storage. Explicit withdraw+primary receipt is the revocation mechanism; changing an env flag alone is not a claim of cancellation of an already-running provider write.
