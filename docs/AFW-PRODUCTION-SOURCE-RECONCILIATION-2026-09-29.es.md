# AFW: conciliar el código productivo con Git

**Proyecto:** Agent Friendly Web. **Repositorio:** `tokenizartinfo-ops/agent-friendly-web`. **Rama de propuesta:** `feat/afw-release-reconciliation-20260929`, desde `origin/main` `ea77f59ee9ed319a1253645ef89e2b3c16951b6f` (02/09/2026). **Entorno/origen observado:** Worker productivo `agent-friendly-web-web-production`, `https://agentfriendlyweb.dev`, versión `d7502fb4-4e5b-4a60-abcf-fa4766d4b8a8` al 100% en la verificación previa. **Acción de esta rama:** versionar la fuente del release y sus instrucciones; no desplegar ni modificar D1. **Rollback:** cerrar o revertir esta propuesta Git; el runtime productivo no cambia por la conciliación.

La fuente del release estaba congelada en un `output/` ignorado por Git mientras `main` seguía en un estado anterior. Se copiaron a un checkout limpio los 579 archivos del [manifiesto de la fuente productiva](evidence/afw-production-source-manifest-2026-09-29.json), verificando el SHA-256 de cada origen antes de copiarlo. Los únicos dos archivos de `main` ausentes en ese manifiesto son notas de un incidente de scanner y se conservaron. Se agregaron las notas de release y activación posteriores a la congelación. No se incluyó `wrangler.ledger-production.json`: es una configuración auxiliar antigua sin la compuerta actual del copilot y podría inducir una carga equivocada.

Al comparar el checkout propuesto contra los 579 hashes, solo difieren `AGENTS.md` (instrucciones actuales), `worker-configuration.d.ts` (se limpiaron espacios finales de cinco líneas generadas) y la configuración auxiliar excluida. Los archivos de runtime, esquema y migraciones coinciden con la fuente congelada. La rama agrega al repositorio el manifiesto, cuya huella SHA-256 es `415b43c86c630534df143c0bf27b354d717a1b0c6624679bab19a62dec9f2fc8`.

En el checkout limpio pasaron **508/508 pruebas**, ESLint sin errores (un aviso `<img>` preexistente), `vinext build` y `tsc --noEmit`. `npm ci` no terminó por falta de espacio en C:; para la verificación se enlazó temporalmente el `node_modules` ya instalado del checkout anterior. Una instalación parcial aislada se retiró del árbol del proyecto porque TypeScript la interpretaba como fuente y producía errores ajenos a AFW. Antes de fusionar, CI debe reproducir las pruebas desde instalación limpia. `git diff --cached --check` pasó.

Esta conciliación deja una base versionada y revisable para los siguientes bloques. No activa el copilot para un cliente ni modifica el estado real de AFW; la activación continúa regida por [el procedimiento por expediente](AFW-COPILOT-PER-PROJECT-ACTIVATION-2026-09-28.es.md).
