# Contribuir

Las contribuciones deben preservar el caracter verificable de la metodologia.

## Antes de abrir un cambio

1. Explica que evidencia publica sostiene la modificacion.
2. Distingue estandar estable, propuesta, borrador y herramienta propietaria.
3. No incluyas credenciales, datos privados ni resultados de auditorias no autorizadas.
4. Agrega pruebas cuando cambies normalizacion, scoring, deteccion o intake.
5. Ejecuta `npm test`, `npm run lint` y `npm run build`.

## Claims

No presentes AF-0 a AF-5 como certificacion oficial. No atribuyas indexacion, recomendacion, AEO, MCP, WebMCP o pagos a un sitio si la capacidad no puede reproducirse en su superficie desplegada.
